# Third expansion batch: 2026-10-30

Adds 24 independently audited check swings, increasing the library from 111 to 135. Practice access is immediate; daily eligibility starts October 31 UTC. The previous 111 entries remain exactly as published.

## Recovery and review

New incidents came from contemporary Close Call Sports and predecessor LiveJournal reports. Source recovery linked numeric MLB video IDs to official legacy media assets, including cases where the metadata endpoint failed or returned no playback links. Some files use the next UTC/publication date rather than the game date, and some older renditions use 800K or 400K names. URLs were verified individually, not promoted from guesses. The metadata resolver also now recognizes content_id on older /play and /media paths.

Each addition passed primary and independent review of complete checking motion, usable side perspective, event identity, exact pitch result and date, deciding umpire attribution, and duplicate identity. MLB pitch feeds corrected several misleading source captions and count descriptions. Approved timestamps and exact rendition URLs are preserved together; different encodings can contain different edits. The public provenance JSON records per-pitch source and audit evidence. Source paths pointing to local contact sheets identify retained research artifacts rather than public web files.

Two distinct checks in the same Pujols/Gallardo source video count as separate pitches and have separate records. Framing holds, foul/bunt/contact ambiguity, and unrecovered footage were excluded. The side views approximate the first- or third-base umpire perspective; the footage is ordinary MLB broadcast footage, not an umpire-mounted camera.

The target remains 500; this batch reaches 135. Broader discovery and review continue, and metadata leads are never counted as playable clips.
